# human-clicker

![CI](https://github.com/gizmooo/human-clicker/actions/workflows/ci.yml/badge.svg)

[English](README.md)

Автокликер с «человеческим» поведением: лог-нормальные задержки, разброс позиции, удержание кнопки, передышки, плавное движение курсора.

> **Дисклеймер.** Большинство игр запрещают автоматизацию правилами и могут забанить аккаунт. Используй на свой риск.

## Требования

- Node.js 22.18 или новее, рекомендуется актуальный LTS: TypeScript выполняется нативно, без сборки
- Windows (нативные модули `robotjs` и `uiohook-napi`; macOS/Linux не проверялись)

## Установка

```
npm install
```

## Запуск

```
npm start                        # лимит 60 минут, язык по системной локали
npm start -- --max 30            # лимит 30 минут
npm start -- --lang ru           # принудительный язык: en, ru, es, zh
```

Или двойной клик по `start.cmd`: проверяет наличие Node и модулей, при необходимости ставит зависимости, пробрасывает аргументы.

После запуска есть 5 секунд, чтобы навести мышь на цель. Позиция курсора в этот момент становится целью.

## Управление

| Клавиша | Действие |
|---------|----------|
| `Space` | пауза / продолжить (таймер лимита сбрасывается) |
| `Esc`   | выход |

Клавиши ловятся глобально, из любого окна.

Если между кликами увести мышь дальше 30 px, кликер сам встанет на паузу. `Space` продолжает по той же цели.

## Настройки

Объект настроек в `src/clicker.ts`:

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `FIXED_TARGET` | `null` | `{x, y}` для жёстких координат; `null` = позиция мыши при старте |
| `START_DELAY` | 5 | секунд до старта |
| `CLICK_DELAY` | 250 мс, σ 0.25, [150, 500] | интервал между кликами: медиана, разброс, границы |
| `HOLD` | 70 мс, σ 0.3, [40, 150] | удержание кнопки |
| `JITTER_PX` | 3 | разброс позиции ±px |
| `SHIFT_EVERY` | [5, 15] | через сколько кликов сдвигать курсор; после передышки всегда |
| `REST_EVERY` | [20, 50] | через сколько кликов передышка |
| `REST_MS` | [600, 1800] | длительность передышки, мс |
| `AWAY_PX` | 30 | порог автопаузы |

Задержки лог-нормальные: кучкуются у медианы, редкие длинные хвосты. Если нужно безопаснее, подними медиану `CLICK_DELAY` до 350–450.

## Разработка

TypeScript выполняется Node 22.18+ напрямую (встроенный type stripping), сборки нет. Dev-зависимости нужны только для проверки типов, `start.cmd` ставит без них.

```
npm install          # с dev-зависимостями
npm test             # vitest
npm run typecheck    # tsc --noEmit
```

## Файлы

- `src/clicker.ts` — точка входа: аргументы, настройки, горячие клавиши
- `src/engine.ts` — цикл кликов с внедряемыми robot, часами и sleep
- `src/utils.ts` — `logNormal`, `moveSmooth`, `sleep`, `rnd`
- `src/lang.ts`, `src/locales.json` — строки интерфейса (en, ru, es, zh). Новый язык: ключ в `locales.json`
- `test/` — тесты
- `start.cmd` — запуск под Windows
