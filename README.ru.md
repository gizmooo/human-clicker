# Human Clicker 🐭

**Автокликер для Windows на Node.js с поведением живого человека.** Лог-нормальные задержки, переменное удержание кнопки, дрожание курсора, передышки и плавное движение: кликает как рука на мышке, а не как таймер.

[English](README.md)

> **Дисклеймер.** Большинство игр запрещают автоматизацию правилами и могут забанить аккаунт. Этот инструмент делает клики похожими на человеческие, но не делает их невидимыми. Используй на свой риск.

Сделано для тех, кому физически тяжело долго кликать (RSI, ограниченная подвижность), и для idle- и кликер-игр, где автоклик часть жанра.

Версия для Android с той же моделью таймингов планируется после v2.0.0.

## Чем отличается от обычного автокликера

Обычный кликер нажимает каждые N миллисекунд в один и тот же пиксель. Такой паттерн видно невооружённым глазом, и на человека он не похож. Human Clicker моделирует руку, а не таймер:

- **Лог-нормальные задержки.** Интервалы между кликами берутся из лог-нормального распределения (преобразование Бокса–Мюллера). Они кучкуются у медианы с редкими длинными паузами, той же формы, что реальное время реакции.
- **Переменное удержание кнопки.** Время между нажатием и отпусканием каждый раз разное.
- **Дрожание и сдвиги курсора.** Курсор не стоит на одном пикселе вечно. Раз в несколько кликов, и всегда после передышки, он сдвигается на пару пикселей.
- **Передышки.** Каждые несколько десятков кликов короткая пауза, как у руки, которая отвлеклась.
- **Плавное движение.** Курсор едет по кривой разгона и торможения, а не телепортируется.

## В сравнении с другими кликерами

Популярные опенсорсные кликеры (XClicker, oriash93/AutoClicker, clicker-rs) бьют с фиксированным или равномерно случайным интервалом в текущую позицию курсора. Python-библиотеки вроде HumanCursor хорошо моделируют траектории, но это кирпичики для Selenium-скриптов, а не инструмент «навёл и запустил». Human Clicker единственный из них с лог-нормальными задержками, сдвигами курсора, передышками, автопаузой при перехвате мыши и слежением за фокусом окна, и запускается двойным кликом под Windows.

## Возможности

- **Цель по мыши.** Наведи на то, что надо кликать, дождись отсчёта, готово. Жёсткие координаты тоже можно задать.
- **Защитная автопауза.** Увёл мышь в сторону, кликер сам встал на паузу, а не воюет с тобой за курсор.
- **Слежение за фокусом окна.** Переключился по Alt-Tab, кликер ждёт и сам продолжает, когда окно цели снова активно.
- **Глобальные хоткеи.** `Space` пауза и продолжение, `Esc` выход, из любого окна.
- **Лимит времени.** Сам останавливается через 60 минут по умолчанию, забытый кликер не работает всю ночь.
- **Четыре языка интерфейса.** Английский, русский, испанский, китайский, по системной локали.
- **Запуск одним файлом.** `start.cmd` проверяет Node, ставит зависимости и запускает кликер.

## Быстрый старт

1. Установи [Node.js](https://nodejs.org), 22.18 или новее, рекомендуется актуальный LTS.
2. Скачай проект ([zip](https://github.com/gizmooo/human-clicker/archive/refs/heads/master.zip) или `git clone`) и распакуй.
3. Двойной клик по **`start.cmd`**. Он доставит недостающее и запустит кликер.
4. Есть 5 секунд навести мышь на цель. Дальше кликает, пока не нажмёшь `Esc`.

Из консоли:

```
npm install
npm start                        # лимит 60 минут, язык по системной локали
npm start -- --max 30            # лимит 30 минут
npm start -- --lang ru           # принудительный язык: en, ru, es, zh
npm start -- --help
```

`start.cmd --max 30` тоже пробрасывает аргументы.

## Управление

| Клавиша | Действие |
|---------|----------|
| `Space` | пауза / продолжить (таймер лимита сбрасывается) |
| `Esc`   | выход |

Если между кликами увести мышь дальше 30 px, кликер сам встанет на паузу. `Space` продолжает по той же цели.

Окно цели запоминается после первого клика. Пока активно другое окно, кликер ждёт и сам продолжает, когда цель снова в фокусе.

## Настройки

Объект настроек в `src/clicker.ts`:

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `fixedTarget` | `null` | `{x, y}` для жёстких координат; `null` = позиция мыши при старте |
| `startDelay` | 5 | секунд до старта |
| `clickDelay` | 250 мс, σ 0.25, [150, 500] | интервал между кликами: медиана, разброс, границы |
| `hold` | 70 мс, σ 0.3, [40, 150] | удержание кнопки |
| `jitterPx` | 3 | разброс позиции ±px |
| `shiftEvery` | [5, 15] | через сколько кликов сдвигать курсор; после передышки всегда |
| `restEvery` | [20, 50] | через сколько кликов передышка |
| `restMs` | [600, 1800] | длительность передышки, мс |
| `awayPx` | 30 | порог автопаузы |
| `trackFocus` | `true` | пауза, пока окно цели не в фокусе |

Профиль по умолчанию даёт 3–4 клика в секунду. Для более спокойного подними медиану `clickDelay` до 350–450.

## Разработка

TypeScript выполняется Node 22.18+ напрямую (встроенный type stripping), сборки нет. Dev-зависимости нужны только для проверки типов и тестов, `start.cmd` ставит без них.

```
npm install          # с dev-зависимостями
npm test             # vitest
npm run typecheck    # tsc --noEmit
```

- `src/clicker.ts` — точка входа: аргументы, настройки, горячие клавиши
- `src/engine.ts` — цикл кликов с внедряемыми robot, часами и sleep
- `src/utils.ts` — `logNormal`, `moveSmooth`, `sleep`, `rnd`
- `src/lang.ts`, `src/locales.json` — строки интерфейса. Новый язык: ключ в `locales.json`
- `test/` — тесты
- `start.cmd` — запуск под Windows

Нативные модули `robotjs`, `uiohook-napi` и `get-windows` идут с готовыми сборками под Windows. macOS и Linux не проверялись.

Планы по фичам в [issues](https://github.com/gizmooo/human-clicker/issues).
